# Контроль складских остатков в 1С 8.3

Учебный проект на встроенном языке 1С. Модуль рассчитывает остатки по складам и артикулам из журнала приходов и расходов и показывает первую строку, которая нарушает правила учёта. Используются демонстрационные данные.

## Правила расчёта

- Журнал должен быть отсортирован в порядке проведения движений. Склад и артикул образуют ключ остатка. Пробелы по краям игнорируются.
- Приход увеличивает остаток, расход уменьшает его. Движение с нулевым или отрицательным количеством отклоняется. Расход, превышающий остаток на своём складе, отклоняется даже при последующем приходе.
- Результат сортируется по складу и артикулу. Позиция с нулевым остатком сохраняется в результате.

## Как запустить

1. В тестовой конфигурации 1С:Предприятие 8.3 создай неглобальный общий модуль `СкладскойКонтроль` с установленным свойством «Сервер». Скопируй в него [`src/StockControl.bsl`](src/StockControl.bsl).
2. Добавь управляемую обработку с командой `Проверить` и назначь ей обработчик `Проверить`. Скопируй [`examples/DemoForm.bsl`](examples/DemoForm.bsl) в модуль формы этой обработки.
3. Обнови конфигурацию базы, запусти обработку и нажми «Проверить». В сообщениях должен появиться текст `Проверки пройдены: остатки, нулевой остаток и блокировка перерасхода.`

Демо проверяет независимость остатков на двух складах, списание ровно до нуля и ошибку при перерасходе. Исходники предназначены для запуска в тестовой конфигурации. Для расчёта не требуются справочники, регистры и внешние компоненты.
